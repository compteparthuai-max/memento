# Memento

Vitrine de livres fondée sur le reset LittleLink (licence MIT dans LICENSE.md), personnalisée en HTML/CSS/JavaScript.

Site : https://compteparthuai-max.github.io/memento/

## Ajouter un livre
Déposer sa couverture WebP à la racine, puis ajouter une entrée dans books.js. Renseigner id, title, subtitle, category, image, order et formats. Chaque format contient name et amazonUrl. featured place un livre en tête. available: false suspend le lien d’achat. Les catégories sont calculées automatiquement.

Le rendu est dans app.js et le style dans styles.css. instagramUrl dans books.js affiche le lien Instagram une fois renseigné.

## Publication
GitHub Pages publie automatiquement la branche main, dossier racine. Aucun abonnement, serveur ou compilation nécessaire.

Les couvertures et le logo appartiennent à leurs titulaires ; la licence LittleLink porte sur son code.
